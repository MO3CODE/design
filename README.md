# استوديو تصاميم بوابة المستثمر

موقع يحوّل **خطة المحتوى (Excel)** إلى تصاميم سوشال جاهزة للنشر، بنفس آلية مهارة `investors-gate`: نفس المحرك (`slide.html`)،
نفس الإعدادات المعتمدة (presets)، نفس سجل الذوق، ونفس الفحوصات. والإخراج النهائي بدقة **3×** (منشور 3240×4050).

```
ارفع التقويم ← المنشورات تنقسم تلقائياً (النوع، الخدمة ولونها، الشرائح، الكابشن)
      ← ارفع الصور/الأصول ← «صمّم الآن»
      ← فكرة + spec ← رسم بالمحرك ← فحص آلي (تداخل/حواف/تباين/إملاء) ← إصلاح ← فحص بصري بعين الموديل
      ← ملاحظاتك بالعربي («كبّر الأصل شوي») ← نسخة جديدة ← قارن جنب بعض ← اعتماد ← ZIP بأعلى جودة
```

## المزايا

| | |
|---|---|
| **استيراد التقويم** | نفس منطق `calendar.py`: يقسم «المحتوى للتصميم» على الشرائح، يكتشف الخدمة واللون (`svc_investor`، `svc_formation`…)، ويفصل الهاشتاقات |
| **معاينة حية حقيقية** | المتصفح يرسم بنفس `engine/slide.html` — اللي تشوفه هو نفسه اللي ينطبع 3× |
| **مصمم ذكي** | يكتب spec بالـ preset المعتمد، يرسم، يصلح أخطاء الفحص، ويفحص التصميم المرسوم بصرياً قبل ما يسلّمك |
| **تعديل بالمحادثة** | التعديلات الصغيرة ترجع كـ *patch* (سطرين) بدل إعادة كتابة التصميم — أسرع وأرخص بكثير |
| **خيارات للمقارنة** | «خيارات بديلة» تطلع اتجاهين مختلفين ويفتح المقارنة جنب بعض |
| **سجل الذوق** | كل اعتماد/رفض مع السبب ينضاف للسجل ويُرسل مع كل تصميم قادم |
| **الإخراج النهائي** | `NN.png` (3240×4050) + `NN_2160.jpg` + `NN_1080.jpg` (جودة 97، 4:4:4) + `preview.jpg` + `strip.jpg` + `caption.txt` + `qc.json` + `spec.json` في ZIP |
| **محرر JSON** | للتعديل اليدوي الدقيق مع معاينة لحظية |
| **صرف التوكن المباشر** | عدّاد بالشريط الجانبي يتحدث لحظياً، وصفحة كاملة: دخل/طلع/تفكير مخفي/كاش/صور — حسب الموديل والمهمة والمنشور واليوم، مع صرف كل منشور وكل مهمة، وجدول أسعار تعبّيه (RadoxAI ما ينشر أسعار) |
| **توليد بـ GPT Image** | عنصر شفاف أو صورة كاملة أو خلفية من وصف عربي (يتحول لبرومبت بأسلوب الهوية بدون نصوص)، بمرجع اختياري، والنتيجة تنضاف لصور المنشور — وزر «ولّد» جنب كل صورة يطلبها المصمم |

## التوجيه الذكي بين الموديلات (توفير التوكن)

كل طلب يروح لأرخص موديل يقدر يسويه صح، ويصعد تلقائياً للمستوى الأقوى **فقط لو فشل** (JSON غلط، رد مقطوع…):

| الطلب | المستوى | ليش |
|---|---|---|
| تصميم جديد من المحتوى · إعادة الفكرة («ما عجبني، غيّر الفكرة») | **القوي** | إبداع + فهم كل القواعد |
| خيارات بديلة · تعديل متوسط · إصلاح أخطاء الفحص | **المتوازن** | جودة عالية بتكلفة أقل |
| تعديل صغير (كبّر/صغّر/حرّك/لون/اقلب) · تدقيق الكابشن | **السريع** | يرجع patch صغير فقط |
| الفحص البصري للتصميم المرسوم | **البصري** | لازم يشوف الصورة |

وفوق اختيار الموديل:
- **التعليمات مقسّمة لوحدات** — التصميم الجديد ياخذ دليل المهارة كامل (~15 ألف توكن)، والتعديل الصغير ياخذ ملخص الحقول فقط (~1.5 ألف).
- **تصنيف الملاحظة محلياً** بدون استدعاء موديل (صغيرة/متوسطة/كبيرة).
- **الصور** تُرسل مصغّرة (512px) وفقط للطلبات اللي تحتاجها.
- الأوضاع: `smart` (موصى) · `economy` (يبدأ أرخص ويصعد عند الفشل) · `quality` (الأقوى دايماً).
- الموديلات تُكتشف تلقائياً من `GET /v1/models` بالمنصة (الأحدث من كل عائلة)، أو حدّدها يدوياً من الإعدادات.

## المزوّد: RadoxAI

الافتراضي [RadoxAI](https://radoxai.com/docs) — واجهة متوافقة مع OpenAI (`POST /v1/chat/completions`، `Authorization: Bearer`،
الصور كـ `image_url` base64، البث SSE مع `usage` بآخر قطعة). ويدعم أيضاً **Anthropic مباشرة** (`AI_PROVIDER=anthropic`) مع كاش
للتعليمات الثابتة (أرخص ~90% على الجزء المكرر).

> المفتاح يبقى على السيرفر فقط (`.env` أو صفحة الإعدادات) — ما يوصل للمتصفح أبداً. **لا تحطه بـ `.env.example`** (هذا ينرفع لـ GitHub).

## الأصول بـ GPT Image

- **الجزء النصي** (قراءة التصميم، تقرير الأصل المناسب، كتابة البرومبت، ترجمة تعديلاتك) بموديل **GPT من RadoxAI** (`gpt-5.6-sol` تلقائياً، أو اختر من الإعدادات).
- **رسم الصورة** عبر **RadoxAI بنفس المفتاح** (`/images/generations` و`/images/edits`، الموديل الافتراضي `gpt-image-2.5-flare`).
  ⚠ حتى 2026-10-14 RadoxAI ما فعّل `/images` على الحساب (404) — الميزات جاهزة وتشتغل أول ما يفعّلونه؛ تأكد بزر «اختبر رسم الصور» بالإعدادات.

| الأداة | وش تسوي |
|---|---|
| **أصول تلقائية** (بلوحة المصمم) | يقرأ التصميم المعروض (صورة الشرائح + spec + النص) ويقرر: **عنصر** شفاف (`photo` cutout) أو **طبقة خلفية شفافة** خلف المحتوى (`bg_photo`) أو الاثنين — يولّدها ويركّبها ويطلع نسخة جديدة مفحوصة |
| **تعديل الأصل** (زر «عدّل» على الصورة) | تكتب التعديل بالعربي ← يتعدّل **نفس الصورة** (images/edits) ← نسخة r2, r3… مربوطة بالأصل وسجلها محفوظ، وتنستبدل بالتصميم تلقائياً؛ وتقدر ترجع لأي نسخة سابقة |
| **ولّد يدوياً** | عنصر شفاف / صورة كاملة / خلفية من وصف عربي، بمرجع اختياري |

## التشغيل المحلي (ويندوز)

المتطلبات: **Node 20+** و**Chrome أو Edge**. (اختياري: Python 3.11 + `rembg` لقص الخلفية التلقائي — نفس بيئة المهارة.)

```bash
npm install
```
```bash
copy .env.example .env
```
عدّل `.env` وحط `RADOX_API_KEY`، ثم:
```bash
npm run build
```
```bash
npm start
```
افتح <http://localhost:8787>. للتطوير مع إعادة التحميل التلقائي: `npm run dev` (الواجهة على 5173).

### الخطوط
خطوط **ثمانية** و**IBM Plex** و**Cairo** داخل الريبو. خطوط **Expo Arabic** و**Bahij** تجارية فـ**ما تنرفع** للريبو —
انسخها من `%USERPROFILE%\.claude\skills\investors-gate\assets\fonts` إلى `engine/assets/fonts` (أو أي مجلد وحدّده بـ `FONTS_DIR`).
بدونها يرجع المحرك تلقائياً لـ IBM Plex وصفحة الإعدادات تبيّن الناقص.

## النشر على سيرفر (Docker)

```bash
docker compose up -d --build
```
- ضع ملفات Expo/Bahij في `./fonts-private` والبيانات تنحفظ في `./data`.
- `WITH_CUTOUT=1` (الافتراضي بـ compose) يثبّت بايثون + rembg لقص الخلفية — الصورة أكبر (~1.5GB). اجعله `0` لو بترفع أصول PNG مقصوصة دايماً.
- **فعّل `APP_PASSWORD`** قبل ما تفتحه على الإنترنت، وحطه خلف HTTPS (Caddy/Nginx).

data/                المشاريع والصور والنسخ والإخراج + settings.json + taste-log.md + usage.jsonl (خارج git)

## مزامنة مع المهارة

لو طوّرت مهارة `investors-gate` (ثيم جديد، preset، قاعدة بسجل الذوق)، انسخ الملفات المتغيرة:
`templates/slide.html → engine/slide.html` · `presets.json` · `brand.json` · `references/*.md → engine/knowledge/` · `assets/`.
سجل الذوق الحي للموقع بـ `data/taste-log.md` (يبدأ من نسخة المهارة ويتطور من الاعتماد/الرفض).

## الـ API (مختصر)

| | |
|---|---|
| `POST /api/projects` | رفع التقويم (`file`) أو مشروع فارغ (`name`) |
| `POST /api/projects/:pid/posts/:id/photos` | رفع صور (`photos[]`) |
| `POST …/design` · `…/revise {feedback}` · `…/variants {count}` · `…/caption` · `…/manual {spec}` | بث NDJSON بالتقدم |
| `POST …/prepare {spec}` | spec جاهز للمعاينة الحية |
| `POST …/export {versionId}` ثم `GET …/exports/:eid/zip` | الإخراج النهائي |
| `GET/PUT /api/settings` · `GET /api/models` · `GET /api/usage` · `GET/PUT /api/taste` | الإعدادات والموديلات والتكلفة وسجل الذوق |
